## 1. 诚实的问题陈述

本实验**不是**要证明"我们估平移比相位相关准"。在固有失配 ≈ 0 的
LEVIR 上，注入的是**纯全局平移**，稠密相关类方法本来就该做得很好——
预期它们在这一项上表现强劲，这一点必须写进论文而不是回避。

真正的问题是：给定**同一个冻结检测器**、**同一个 warp**，经典估计器
能否达到学习式选择性路由的工作点，**且不损伤 clean 对**？

```text
经典方法估的是光度位移；学习式定位器估的是任务坐标位移。
在固有失配≈0 的数据集上二者重合，所以 LEVIR 上的强经典结果是
预期之内；差异只可能出现在固有失配非零处（S2Looking 的干预式
证据，主记录 61/63）。本节把这一点当作已知前提写明。
```

## 2. 设计：一个检测器、一个 warp、四个估计器

```text
估计器：phase correlation / ECC（相位初始化，失败回退相位）/
        SIFT + 确定性 RANSAC 共识（仅平移模型）/ 本文定位器
变体：  always（无条件对齐）与 gated（|offset|∞ >= 1 px 才对齐；
        本文方法的 gated 即 q gate）
场景：  clean / S1 / S4 / S8，与 P7-3 协议逐字段相同
指标：  逐场景 F1、相对 raw 的增益、clean 掉幅、对齐选择率、
        位移估计的 mean EPE 与 PCK@1/2、每图耗时
```

SIFT 只允许平移模型，与学习式定位器的表达能力一致——不给任何一方
额外自由度。RANSAC 共识是**确定性**的（在全部匹配上取最大一致集，
无随机采样、无种子），保证可复现。

## 3. 预注册判据（有牙齿的那种）

参照点 = P7-3 seed-3407 记录值：shift mean gain 0.0821，clean drop 0.0。

```text
某经典变体"达到参照"当且仅当同时满足：
  shift mean gain >= 0.0821 − 0.005
  clean drop      <= 0.001
两条**都要**：靠损伤 clean 换取位移性能，正是路由器存在的理由。

存在达到参照的经典变体 → verdict =
  classical_sufficient_restate_contribution
  后果（预先写死）：定位器在 LEVIR 上不构成贡献，论文必须改述为
  以选择性路由、适用域判据、任务坐标≠光度坐标的干预证据为主，
  并如实报告该对照表。**不得隐藏、不得只报对我们有利的变体。**
无 → verdict = learned_selective_router_justified，报告差距幅度
```
