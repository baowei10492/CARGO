## 1. 缘由

```text
F1 关（§192.7）只用定位器自带的错位概率做开关：DSIFN、WHU 正收益；LEVIR 第 3 档 +32 个点，
  但 22% 的干净小块被挪动，干净 F1 下降 1.74 个点，未过 0.5 个点的线
原计划（P25 协议第 5 节第 3 步）本就要按「检测器 × 数据集」训练选择器，决定每对是否校正；
  旧选择器（P7-3 safe_veto_task）的输入是平移定位器的量，不能直接用，需按同一配方重训
必须披露：本修订写于看到 F1 关验证集结果之后；判定标准沿用 §192.6，不另放宽
```

## 2. 冻结与不变的部分

```text
定位器：P27 第一版 best.pth（第 40000 步），不改；检测器：F1 关所用的三个冻结检查点，不改
扰动、小块、打分像素、F1 计算：与 F1 关完全相同
验证集：本步骤再读一次（F1 关之后的第二次，也是第一版定位器的最后一次）；
  至多评估一个选择器版本（工具以选择器文件的 sha256 写一次性标记，并检查定位器的 F1 关标记已存在）
测试集不碰
```

## 3. 训练数据（只用训练集）

```text
来源：各数据集训练集瓦片的 256 px 不重叠小块；每块取干净 + 三档扰动（与验证集同一扰动族，随机数按小块编号生成）
划分（按瓦片）：
  校准段 = 定位器训练时留出的 5% 瓦片（定位器没见过）的全部小块
  其余瓦片的小块按间距均匀取至多 3000 块，按瓦片哈希分为拟合 85% / 早停 15%
标签：advantage = 任务损失(raw) − 任务损失(estimated)，任务损失 = 检测器训练时的 BCE + Dice（含 pos_weight），
  在打分像素上计算；safe = advantage > 0
样本权重、网络结构、优化、早停：与 P7-3 完全相同（clamp(|adv|/0.05, 0.05, 4)，unsafe ×3，干净且 unsafe 再 ×2；
  MLP 32-16，AdamW 1e-3，至多 300 轮，早停耐心 60，CPU 确定性训练）
特征（19 个，部署时都可得，不读标签）：
  定位 6 个：错位概率；估计的平均位移；|log 缩放|；中心点位移；正反一致性（输入对上 T1→T2 与 T2→T1 估计复合后的平均位移）；
    估计变换下仍在图内的像素比例
  任务 13 个：P7 的 raw / aligned 两路检测差异特征（公式不变），在「估计变换下仍在图内」的像素上计算
```

## 4. 阈值与部署规则

```text
选择器（主方法）：P(safe) >= tau 时校正，否则保持原图；对所有小块判断（可补上定位器漏判的错位）
阈值 tau：在校准段上，从 0.50、0.51 … 1.00 中取使「校准段干净 F1 下降 <= 0.0025」的最小值
  （0.0025 为 §192.6 允许值 0.005 的一半，给验证集留余量）；都不满足则不校正
报告（不作判据）：selector_veto（错位概率 > 0.5 且 P(safe) >= tau 才校正，旧 P7-3 的否决式规则）；
  F1 关的 gated；loss_oracle（按标签选两路中损失较低者，不可部署的上限）；校准段上的对应数字
```

## 5. 验证集判据（每个数据集独立，与 §192.6 相同）

```text
主路径 selector：第 2、3 档 F1(selector) − F1(raw) 均 > 0，且干净 F1(raw) − F1(selector) <= 0.005
  → positive_gain；否则 no_positive_gain
仪器检查：本次重算的 raw / oracle / estimated / gated 四路 F1 须与 F1 关的结果一致（绝对差 <= 0.001），
  不一致则不报告选择器数字（anchor_failed）；干净 raw F1 >= 0.50，干净 oracle 与干净 raw 相同
```

## 6. 顺序

```text
第一步（训练侧，不读验证集）：提特征 → 训练 → 校准；打印校准段结果
第二步（验证集，一次）：用户看过校准段结果后再运行；若校准段上选择器在第 2、3 档都没有收益，
  则不运行第二步，如实记录
```
