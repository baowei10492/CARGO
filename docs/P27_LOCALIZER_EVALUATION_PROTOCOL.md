> 本文件与 `configs/p27_eval_perturbation.yaml` 写于任何 P27 定位器训练或评估之前；看到任何 P27 验证集结果后不得修改。

---

## 1. 评估对象与数据

```text
被评估者：P27 第一版定位器（平移 + 等比缩放；冻结 DINOv3 + 适配层；变化感知；错位概率头），
  由 tools/train_similarity_localizer.py 在 LEVIR / DSIFN / WHU / GZ-CD 的训练集上训练，
  开发决策只看训练集中按哈希留出的 5%（保留集），检查点按保留集第 2、3 档成功率均值选出（best.pth）
数据：P25 的三个数据集验证集（LEVIR-CD、DSIFN-CD、WHU-CD），与 P25 完全相同的 600 个 256 px 小块
扰动：P25 的三档（平移 ±25 px 与缩放 0.80–1.25 的 1/3、2/3、全幅；每块的随机数与 P25 相同），旋转固定为 0；
  扰动作用于 T2，T1 为参照
对照：RoMa + 相似变换拟合在同一配置下的结果（tools/run_p25_affine_step1.py，同一 600 块、同一扰动）
```

## 2. 判据（与 P25 相同）

```text
成功：估计收敛，且「直接对扰动真值」与「相对同块干净估计」的网格平均传递误差中较小者 <= 2 px
每个数据集：第 2、3 档成功率均 >= 0.80 → proceed_to_step2；否则 stop_localizer_insufficient
报告（不作判据）：第 1 档；干净小块的触发率（本定位器以错位概率 > 0.5 为触发，设计目标 <= 0.10）；
  干净小块估计位移；按小块变化占比分箱的第 3 档成功率与干净触发率；每块耗时
```

## 3. 使用次数与纪律

```text
每个冻结检查点只允许在验证小块上评估一次（工具以检查点 sha256 写一次性标记）；
  至多两个不同的冻结版本可以评估（第一版，以及至多一次有书面修订依据的改进版）
第二个版本的改动只能依据保留集结果与验证集上的无标签诊断，并须先写修订
训练与开发期间不读取任何验证集或测试集；测试集只在后续步骤（F1、选择器）通过后各用一次
```

## 4. 之后

```text
proceed_to_step2 的数据集：另写实现说明，进入 F1 关（P25 协议 §4 的判据）与选择器关（P25 协议 §5），
  检测器为本文 DINOv3 检测器；之后扩展到其他检测器，最后一次性测试
消融与泛化（留一数据集、错配扰动训练、各模块去除）在保留集上进行；若需要在验证集上报告，计入第 3 节的版本数
```

## 5. 事前预期（写于训练前，不作判据）

```text
LEVIR：最有希望达到 0.80（RoMa 在含旋转的 P25 上约 0.45；去掉旋转并经过双时相训练后应明显提高）
DSIFN：场景多样、变化面积大，中等把握
WHU：256 px 小块仅约 19 m，内容少，风险最大
干净触发率：训练中 30% 为恒等样本，预计明显低于 RoMa（P25：50–70%）
```
