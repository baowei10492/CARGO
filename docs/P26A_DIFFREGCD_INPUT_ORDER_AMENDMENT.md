## 0. 缘由（必须披露）

```text
P26 按 DiffRegCD README 的字面把被扰动图作为其输入「A」，自配对标定在 8 种约定下均失败（38–54 px，§191.1）
事后只读诊断（§191.3，每数据集 5 个自配对，不读标签）：
  被扰动图作 A：与训练真值场的平均余弦 −0.21 / −0.10，端点误差 38 / 45 px
  未扰动参照作 A、被扰动图作 B：平均余弦 0.93 / 0.95，端点误差 8.5 / 9.3 px
  → 网络要求 A 为未扰动参照（位移场在 A 的网格上指向 B，与其训练代码「采样 B 特征对齐到 A」一致），README 的标注与代码不符；
    P26 的失败主要是本项目的接入错误
  同一图像对自身时报出 15 / 22 px 位移（真值 0）
本修订写于看到上述诊断之后；诊断只用自配对，未测量任何真实双时相小块
```

## 1. 修订内容（只有两处实质改动）

```text
1. 输入顺序：A = 未扰动的 T1，B = 扰动后的 T2
   扰动对象随之改为 T2，与 P25（RoMa）完全相同 —— 同一小块、同一扰动矩阵、同一图像被扰动，两者可逐行对比
   自配对标定仍用 T1 对自身第 3 档扰动（A = T1，B = 扰动后的 T1）
2. 标定结果的处理：
   约定有歧义（最佳者不优于其他符号 / 网格约定的 0.5 倍，或从未收敛）→ 停止（selfcheck_failed）
   约定明确但最差自配对误差 > 2 px → 仍测量真实小块，结果只作描述；判定记为 selfcheck_imprecise，
     第 1 步判据（第 2、3 档成功率 >= 0.80）的结果另记为 descriptive_verdict，不构成通过
   两者都满足 → 与 P26 相同，按判据给出 proceed_to_step2 / stop_localizer_insufficient
其余全部沿用 P26：数据集（LEVIR、DSIFN；WHU 排除）、权重与 sha256、特征时间步与层、8 种约定、拟合参数、
  触发阈值、小块选择、误差与成功规则、变化分箱；报告写到 reports/p26a_diffregcd/step1/
```

## 2. 用途与口径

```text
若 selfcheck_imprecise 或 stop_localizer_insufficient：DiffRegCD 的配准头作为「按数据集训练的定位器」一行进入定位器对比表
  （P7C / RoMa / DiffRegCD / 自研），不作为本文流程的定位器
论文须写明：P26 首次接入时输入顺序错误、事后诊断、本修订，以及其配准头在无错位时报出 15–22 px 位移
```
