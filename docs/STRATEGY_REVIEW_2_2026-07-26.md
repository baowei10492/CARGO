### 1.3 八条知识资产（论文的智力骨架）

1. 对齐必须在 backbone 之前的输入级做（后编码残差恒存）；
2. "存在位移"与"对齐有益"必须解耦（P7-1B）；
3. benefit 回归失败于排序错乱，二分类安全性可行（P7-2→P7-3）；
4. 不对称"高召回触发 + 高精度否决"优于任何单阈值选择；
5. **证据的角色依赖性**：选择角色需要任务证据，否决角色主要需要
   几何证据（消融反转，三种子稳定）；
6. **光度位移 ≠ 任务坐标额外失配**（两数据集独立证据：phase
   correlation 固有残差 + 迁移失败 + 再锚定部分成功）；
7. **检测器适应定律**：在固有错位数据上训练的检测器会把错位吸收
   进权重，可恢复 headroom 随之缩小（解释 S2Looking oracle 之小）；
8. 域饱和是可测量的失败模式（boundary_fraction 指标）。

## 2. C2b-R 的情景树与诚实先验

按协议门槛与预声明归因判读，三种结局：

```text
情景 A（判断：最可能）：S8 显著解锁（boundary 大降、pck 上行），
  S4 pck2 仍在 0.5–0.7 段 → conditional 门槛仍不过 → 预注册止损。
  依据：S4 的问题只有 17% 来自边界，其余是固有场异质性——
  delta_pck1 仅 ~0.22-0.31 说明逐图存在 1–2 px 的非全局散布，
  任何全局平移估计在 @1 精度上都无法击穿。
情景 B：S4/S8/clean 全过 → 进入链步（q 校准/特征/P7-3 复刻）。
  即便如此，S2Looking headroom 极小，最终带标签评估更多证明
  "无害"而非"大增益"。
情景 C：S8 仍被卡（固有尾部超 ±12）→ 直接止损。
```

关键点：**三种结局都有事先写好的出口**，不存在"结果不好就不知道
怎么办"的状态。情景 A/C 的止损不是损失——第 1.3 节资产 6/7/8 正是
从这条级联里挖出来的，止损后 S2Looking 以"三重机制分析"入文。

## 3. 论文形态评估（对照第 2 节二区清单）

当前论点已被失败打磨得更锋利：

```text
在配准良好的数据上，风险受控的选择性输入级配准可以
clean 零损地恢复错位性能（LEVIR，全门槛 + 多种子）；
在固有错位数据上，光度配准注定失配任务坐标系，
正确行为是"知道何时不对齐"（S2Looking，机制三重奏）。
```

对照清单的缺口：

| 要求 | 状态 |
|---|---|
| 可部署无损路由 | 完成（LEVIR） |
| 路由多种子 | 完成；**检测器仍单种子（遗留风险）** |
| S2Looking 外部验证 | 大概率转为机制分析 → **"第二个成功数据集"空缺是当前论文最大风险** |
| 与近期方法比较 / 消融 / 效率 / 自然错位 / 失败案例 | 素材多已存在，实验未跑 |
| test 一次 | 等全部冻结 |

审稿人最可能的三板斧：只有一个成功数据集；只有全局平移；为何不用
现成配准预处理。第三个已有 phase correlation 证据、补 SIFT/ECC 即闭环；
前两个是下节新方向要解决的。

## 4. 新方向建议（相对评审 1 的增量）

### 4.1 建议 A（最重要）：WHU-CD 作为第二个"域内"成功数据集

S2Looking 教会我们方法的适用域条件：固有失配场要小。那么正确的
复制实验不是硬啃域外数据集，而是再找一个**域内**数据集验证可复制性：

```text
候选：WHU Building CD（航空影像、配准质量好、社区标准数据集；
      备选 SYSU-CD）
流程：完全复用已验证配方——数据审计 → P3b 训练 → 双路径
      Oracle → P7-1B/1C → P7-3 复刻 → 多种子
成本：P3b 数小时 + 链条各步（工具全部现成，只写配置和协议）
收益：论文变成 2 个域内成功 + 1 个域外机制分析——
      "第二成功数据集空缺"这个最大风险被直接消除
```

这不是换数据集凑通过：论文明确声明适用域条件（固有场小），在两个
域内数据集验证、在域外数据集给出可测量的失效判据（见 4.2），
S2Looking 结果全文透明呈现。需要用户下载数据集（按工作方式约定）。

### 4.2 建议 B（几乎免费、化失败为方法组件）：配准卫生诊断

C2 诊断工具反过来用，就是一个**部署前判据**：

```text
对任意目标数据集的 clean 对跑一次无标签 offset 诊断（几分钟）：
  固有估计幅度分布（median、>4px 占比）、q 触发率
预测：固有场小（如 LEVIR 型）→ 选择性对齐可恢复大部分 headroom；
      固有场大（S2Looking 型）→ headroom 本身已被检测器吸收，
      正确策略是拒绝对齐
```

先在 LEVIR val clean 上跑一次（预期固有估计集中在最小壳层，与
S2Looking 的 median 2.83 形成鲜明对照），若加上 WHU 就有三个点，
可以画出"固有场强度 → oracle headroom → 方法增益"的经验规律。
这把 Stage C 的失败直接转化为论文的一个可交付组件（部署决策程序），
也正面回应 NRCD 一类"合成平移不够"的批评。

### 4.3 建议 C：LEVIR 主攻队列保持不变，优先级微调

P7-5 一致性证据扩充仍是最大单杠杆（+0.047 潜力），且消融反转 +
迁移失败双重强化了它的动机（几何证据 > 任务统计证据）。建议排在
WHU P3b 训练的等待窗口里并行做。P7-4 rescue（+0.018）之后。
P7-6 区域级的动机被 S2Looking 场异质性证据大幅加强——仍留作
下一篇的纵深，但在本篇 discussion 里应作为 future work 明确指出
（引用自己的 C2 诊断数据作为动机，先占住这个叙事）。

### 4.4 建议 D：论文加固清单（不变，重申优先序）

经典配准基线（SIFT/ORB+RANSAC、ECC）> 近期方法 shift 协议对比 >
亚像素/旋转扰动 > 条件执行效率 > AUROC/AURC/ECE（离线可算）。

### 4.5 建议 E：检测器种子风险的最小对冲

P3b 检测器全链单种子（3407）。全链重复三种子成本过高；最小对冲：
在结构全部冻结后、进 test 前，用第二个 P3b 种子重训 LEVIR 检测器
并复刻一次 P7-3（不再做 Phase B），证明结论不系于单一检测器权重。
放在冻结后执行，现在只登记。

## 补记（C2b-R 完成后）

第 2 节的情景树**预测错了**，如实记录：实际结果是第四种情景，而且
比我预设的三种都更有信息量。

```text
预测：S8 解锁但 S4 不过（情景 A，判断为最可能）
实际：boundary 0.794→0.090（域饱和确实解除），但 S8 任务精度
      反而从 pck1 0.632 掉到 0.316、EPE 2.16→3.24
```

原因：radius 4 时的高 pck1 大半是**钳制伪命中**——估计被钳在 ±8
边界，而注入恰好 8 px，钳制值偶然等于任务答案。边界在充当意外的
正则器。解除后估计收敛到真实光度峰（10–11 px），任务坐标下更远。

这把"任务坐标 ≠ 光度坐标"从相关性签名升级为**干预性证据**，是
S2Looking 这条失败级联最有价值的产出。附带一条方法学警告值得写进
论文：配准工作若只报 PCK，可能被搜索域边界的钳制伪命中系统性地
误导——这是一个可复现的陷阱。

同时，delta 抵消随注入幅度单调退化（0.884→0.790→0.662）给出新假设：
固有失配是**空间变化场**。这一条既解释了全局平移为何在原理上不足，
也把 P7-6 区域级从"审稿人会问"升级为"我们测出来了"。第 4.2 节
解法 B 的第 4 类证据（多裁剪一致性）因此提前实现为独立诊断
（docs/P7_REGISTRATION_HYGIENE_DIAGNOSTIC.md），一举兼顾机制验证、
部署判据与特征原型三个用途。

对第 4 节方向优先级的影响：WHU-CD（建议 A）与卫生诊断（建议 B）
优先级不变且更紧迫；P7-6（建议 C 尾段）的动机显著增强，但仍留作
下一篇，本篇 discussion 引用自己的瓦片离散度数据作为动机。
