## 1. P7-3 结果在整个项目中的位置

P7-3 是本项目第一个同时满足以下四条的可部署路由：

```text
clean 完全无损（drop = 0.000）
shift mean gain +0.0821（门槛 0.020）
Shift-8 gain +0.1396（门槛 0.050，S8 F1 0.6793 → 0.8189）
Shift-8 Oracle recovery 65.2%（门槛 50%）
```

此前每一条路线都在"clean 安全"与"shift 恢复"之间失败于一侧：
q gate 恢复多但伤 clean（-0.0101）；P7-2 task router 保 clean 但只恢复
57.4% 且过度保守（S8 选择率 21.9%）；suppression 规则两次失败。P7-3
用"高召回触发 + 高精度否决"的不对称结构第一次把两侧同时压进门槛。

正式状态注记：15.1 一致性校验已于当日完成并通过（p72 对照逐位
复现），P7-3 为正式 passed，结构与协议冻结。

## 2. 全记录复盘：每条已死路线的死因

| 路线 | 死因（一句话） | 留下的可复用结论 |
|---|---|---|
| P5a shift augmentation | 让检测器自己扛位移 → clean 与非位移扰动全面受损 | 位移鲁棒性不应压进检测器权重 |
| P5b 局部对应残差 | 53k 参数的修补进不了任务有效路径 | 特征级小修补无效 |
| P5c 深特征全局配准 | 后编码残差 ~0.005–0.015 恒定存在；S2Looking 泛化失败 | 对齐必须在 backbone 之前的输入级做 |
| Phase correlation | 捕捉的是光度最优位移，不是任务坐标系失配；clean 0.903→0.855 | 需要估计的是"额外失配"，不是"最大相关" |
| 简单边界 OR / q 阈值调参 | clean 96.9%→65.6%，纯粹的错误交换 | 确定性规则没有余量 |
| suppression 零阈值/正间隔 | 信号方向弱、幅度无间隔：正间隔保 clean=0 但只剩 14–22% 收益 | 物理启发式在该问题上不可分 |
| P7-2 benefit 回归 | 高容量回归被大收益样本主导，排序错乱（val_34: +0.767 → 预测 -0.822） | 监督目标应是二分类安全性，不是回归收益 |

这条淘汰链的价值在于：当前路线不是被假设出来的，而是七次受控证伪
之后剩下的结构。每一个组件的存在都有对应的失败实验背书——这正是
论文 ablation 一节的骨架。

## 3. 当前路线是否最优

分三层回答。

### 3.1 在当前约束集内：是证据性局部最优

约束集 = {冻结 P3b、无标签部署、逐图全局平移、不碰 test}。在这个集合
内，已尝试的全部替代都被数据淘汰，且 P7-3 的每个设计选择（veto-only、
二分类、方向不变特征、best-epoch、risk-cal 阈值）都直接对应一个已记录
的失败模式。没有证据支持在同一约束集内还存在明显更好的简单结构。

### 3.2 但天花板可以被精确量化（LEVIR val Shift-8）

```text
Oracle 总空间          0.2141
├─ P7-3 已恢复         0.1396  (65.2%)
├─ 分类器过度否决缺口   0.0565  （q gate 达 0.1961，veto 把 S8 选择率
│                               从 79.7% 砍到 54.7%，砍掉的多为有益样本）
└─ q 召回架构缺口       0.0180  （q 漏掉 13/64，其中 11 张有益；
                                veto-only 结构永远拿不回）
```

优先级由此直接得出：**改进分类器（+0.0565 潜力）> 补 q 召回
（+0.0180 潜力）**。不要先动架构，先动证据质量。

### 3.3 约束集之外：三个结构性上限

1. **逐图全局平移**。第 37.4 节已论证图像级标量门无法表达"局部可对
   齐、局部不可对齐"；真实错位含亚像素、旋转与视差。这是文献叙事
   （第 38.2 节 "When Not to Align"）真正的落点：区域级可匹配性风险
   控制。当前工作是它的图像级实例，可以作为论文主体，但审稿人会问
   区域级与自然错位。
2. **S2Looking 可恢复空间很小**。第 45.2 节：S2Looking 输入级 Oracle
   headroom 仅 S2 +0.004 / S4 +0.013 / S8 +0.033。现行绝对门槛
   （S8 gain >= 0.050）在 S2Looking 上物理不可能达到。Stage C 协议
   必须改成 headroom 相对门槛（如 recovery >= 50%、clean drop <=
   0.001 绝对），否则会重演 P5c 式的"注定失败"。
3. **描述子域差**。Phase 0 已发现 feature path 在 S2Looking 部分失败；
   输入级 descriptor 在 S2Looking 上的 PCK 从未测过。这是 Stage C
   最大的未知数，也是整条路线真正的生死关。

### 3.4 未尝试路线的预判（为什么暂不转向）

- 端到端联合微调（检测器 + 对齐）：P5a/P5c 的证据都指向 clean 受损，
  且文献拥挤（ChangeRD、BiFA、SimSaC）；
- 可学习 STN 前置 + 联合训练：同上，且丧失"冻结专家 + 风险控制"的
  差异化叙事；
- 多假设测试时枚举（对 k 个候选 offset 各跑一次检测器、按置信度选）：
  值得注意的是当前方法本质就是它的 k=2 风险受控版本
  （候选 = {0, 估计 offset}）。k>2 枚举是一个消融轴和潜在加强，
  不是需要改旗易帜的新路线。

结论：路线不需要更换；需要的是把分类器证据做厚、把外部验证做实、
把区域级作为下一篇的纵深。

## 4. "两个信息不能同时兼具"的问题

这个问题在记录里出现过三次形态，值得分开说清。

### 4.1 三种形态

1. **现象层**：q_shift 高召回低精度，task/safe 证据高精度低召回。
   交集（veto）买精度、丢召回；并集在 P7-2 被禁是因为当时回归分数
   错序，并集只会把错误加回来。
2. **量层**：几何上"存在位移"与任务上"对齐有益"本来就不是一个量
   （P7-1B 把它们解耦是本项目最重要的单步进展）。两个量的证据源不同、
   噪声结构不同，任何单一标量都无法同时充分表达。
3. **决策论层**：在两类错误代价不对称（clean 误对齐是灾难、shift 漏
   对齐只是机会成本）时，单阈值决策必然停在 ROC 曲线的某一点上。
   "同时兼具"在单一证据、单一阈值下在数学上就不成立。

### 4.2 对应的三类解法（全部可预注册）

**解法 A：不对称双阈值（rescue + veto），用同一个分数补召回。**
P7-2 禁 OR 的前提是分数错序；P7-3 的分数质量已经不同（靠交集就恢复
65%）。可以预注册：

```text
候选 = q_gate ∪ { P_safe >= tau_rescue }      （rescue 补 q 漏检）
执行 = 候选 ∧ P_safe >= tau_veto              （veto 保 clean）
tau_veto   = 现行规则（clean unsafe 最大分 + eps）
tau_rescue = risk-cal 全部 clean 样本最大分 + eps（更严，构造性保证
             clean 零新增）
```

上限 +0.018 S8 F1。零新训练，复用已训练分类器，训练侧校准，一次
validation。这是"两个信息融合"的正确形式：同一证据轴上的两个不对称
操作点，而不是两个噪声信号的布尔运算。

**解法 B：扩充正交证据，把 ROC 整体推向左上（主攻，+0.0565 潜力）。**
当前 25 维特征全部来自"一次前向的静态摘要"。尚未使用的、无标签、
确定性的证据至少有四类：

```text
1. 循环/幂等一致性：对 (t1, warp(t2, offset)) 再跑一次估计器，
   真位移 → 二次估计 ≈ 0；幻觉位移 → 二次估计漂移。
2. 方向对称性：offset(t1→t2) 与 offset(t2→t1) 应互为相反数。
3. 相关面结构：支持该位移的局部区域占比、峰的多重性、top-k 间隔
   （第 37.2 节原因 B 指出的信息，正是现在被全图平均丢掉的）。
4. 多裁剪一致性：四个象限各自独立估计 offset 的一致程度
   （全局平移假设成立时应一致；视差/伪匹配时发散）。
```

这些特征直接进现有分类器重训（定位器与专家仍冻结），协议改动最小,
而且它们衡量的是"这次对齐本身可不可信"，跨数据集迁移性预期好于
task-disagreement 统计量。

**解法 C：把 trade-off 本身产品化。** risk-coverage 曲线已经实现。论文
不应声称消除了 trade-off，而应展示完整 frontier 并说明操作点选择规则
（clean-zero-risk）。"两个信息不能兼得"从缺陷变成贡献：我们是第一个
把该 frontier 显式校准并给出可解释操作点的。补充 AUROC/AURC/ECE 等
校准指标（第 38.2 节要求的）可以离线从已有 per-sample CSV 计算，属于
报告而非调参，不消耗 validation。

## 5. 后续实验方向（按优先级与信息量排序）

### 第 1 步（必做，已就绪）：Phase B 多种子

`SEED=3408`、`SEED=3409` 各跑一次（split_seed 固定）。除四个门槛的
mean±std 外，重点观察 **tau 的方差**：当前 tau=0.908 由 risk-cal 里
单个 clean unsafe 样本的分数决定，是整条管线对种子最敏感的量。若 tau
跨种子波动大（如 >0.05），第 6 步的阈值规则需要在下一个协议里改成
分位数形式（例如 clean unsafe 的 99% 分位 + eps）——先记录，不现改。

### 第 2 步（信息量最大）：Stage C S2Looking 直迁移

LEVIR 训练的定位器 + q gate + safe classifier 原样迁移 S2Looking val。
预注册协议要点（写协议时落实）：

```text
门槛必须 headroom 相对化：
  clean drop <= 0.001（绝对）
  Shift-8 recovery >= 50%（相对 S2Looking 自己的 input-oracle headroom）
  不设绝对 F1 gain 门槛（S8 headroom 仅 0.033，绝对门槛物理不可达）
先跑无标签诊断：descriptor PCK 与 q 触发率分布（不看标签），
  若定位器本身塌了，直接进入 dataset-specific 重训分支，不浪费评估。
```

Stage C 失败 ≠ 路线失败：区分"定位器域差"（重训 descriptor 分支）与
"分类器域差"（解法 B 的迁移性特征）两种失败模式。

### 第 3 步（廉价）：P7-4 rescue+veto 双阈值

见 4.2 解法 A。建议放在 Stage C 之后：若 Stage C 通过，rescue 是锦上
添花；若 Stage C 暴露分类器域差，rescue 的优先级让位给解法 B。

### 第 4 步（主攻单点）：P7-5 一致性证据扩充

见 4.2 解法 B。这是唯一同时攻击"分类器缺口 0.0565"和"跨数据集迁移"
的方向。预注册时保持：特征只增不改、定位器冻结、同一划分与阈值规则，
与 P7-3 形成严格 ablation 对。

### 第 5 步（下一个层级）：P7-6 区域级 When-Not-to-Align

tile 级（如 4×4）q + veto + 拼接，直接回应第 37.4/38.2 节：局部视差、
局部对应缺失、自然错位。工作量大，建议作为论文的"扩展版"或第二篇，
在图像级故事在两个数据集上站稳之后启动。

### 并行的论文加固项（不改方法，只补证据）

```text
1. 经典配准基线：SIFT/ORB+RANSAC 平移、ECC —— 审稿人必问
   "为什么不用现成配准预处理"；phase correlation 已有数据，
   再补 1–2 个特征点法即闭环。
2. 近期 CD 方法（BIT/ChangeFormer/ChangeDINO 级别）在同一 shift
   协议下的鲁棒性曲线。
3. 扰动泛化：亚像素位移、小旋转、位移超出 ±8 搜索域时
   conditional_boundary 的拒绝行为。
4. 自然错位样例：不注入位移的真实配准残差对上的定性/定量表现。
5. 效率：条件执行（仅 q 触发时跑 Aligned 路径）的 FLOPs/延迟，
   对比恒定双路径。
6. 校准指标：AUROC/AURC/ECE，离线从已有 CSV 计算。
```

### 止损条件（预先写死，防止无限投入）

```text
若 Phase B 中任一门槛的 mean-std 跨过门槛线 → 冻结解除，回到
  分类器稳定性诊断，不加新方向。
若 Stage C 无标签诊断显示 descriptor PCK@1(S8) 在 S2Looking 上
  < 50% → 图像级故事只写 LEVIR + dataset-specific S2Looking，
  论文定位下调，把区域级列为 future work。
若 P7-5 的一致性特征在训练侧 risk-cal 上不能把 S8 retained 从
  79.5% 提到 >= 90% → 接受 65% recovery 作为方法上限，转入写作。
```

## 6. 一句话结论

```text
路线本身已被七次受控证伪筛选出来并首次全门槛通过，不需要更换；
"两个信息不能兼得"应当用不对称双阈值 + 正交一致性证据 + 显式
risk-coverage frontier 三件事去回应，而不是继续寻找单一完美信号；
下一步价值排序：多种子稳定性 → S2Looking 直迁移（门槛必须
headroom 相对化）→ 一致性证据扩充 → rescue 通道 → 区域级扩展。
```

## 补记（15.1 校验后新增的验证集事实）

1. Shift-2 上两个 veto 变体（0.8978）严格优于 q gate（0.8952）：
   veto 在轻位移上不是纯粹的"安全换收益"，而是净改进。
2. 消融反转：veto-registration 在验证集 S4/S8 优于主方法 veto-task
   （S8 0.8282 vs 0.8189，mean gain +0.0862 vs +0.0821，recovery
   69.5% vs 65.2%），且同样通过全部四门槛；而训练侧 risk-cal 上
   task 略优（80.5% vs 78.5%）。方向与 P7-2 的"task 特征显著更强"
   相反，说明：选择角色需要任务证据，否决角色主要需要几何证据。
   这强化了第 4.2 节解法 B 的判断——一致性/对称性等几何证据是
   主攻方向，且 task-disagreement 特征依赖检测器输出统计，
   在 Stage C 跨数据集迁移中是潜在负资产。
3. 决策纪律：正式判定仍按预注册主方法 safe_veto_task 记 passed；
   reg-vs-task 取舍以 Phase B 三种子均值为准，在 Stage C 协议中
   预注册，不据单种子验证结果现场改判。

## 补记 3（Stage C 停止后）

1. 第 3.3 节"描述子域差是生死关"的预警兑现了一半：直迁移在无标签
   门停止（S8 conditional PCK@1 0.486），止损条款按预案执行——
   图像级直迁移故事收窄到 LEVIR，S2Looking 转 dataset-specific。
2. 但证据结构比"描述子塌了"更有趣：EPE 对注入幅度不敏感（~2.9 px
   恒定）+ clean q 触发率 67.2% + 45.3 节固有残差 ~4 px，指向
   H1"任务坐标系失配"：定位器如实估计光度位移（注入+固有），而
   S2Looking 检测器已把固有部分吸收进任务坐标系。若 C2 诊断证实
   H1，这不是路线的失败，而是论文核心命题（"要估计的是任务坐标系
   的额外失配，不是最大相关位移"）在第二个数据集上的独立证据，
   且 C2a 分支（冻结定位器、只重建决策层）成本很低。
3. 该结果同时把第 4.2 节解法 B 的优先级再抬高：跨数据集真正缺的
   是对"这次对齐在任务坐标系里是否可信"的证据，而不是更强的
   光度匹配。
