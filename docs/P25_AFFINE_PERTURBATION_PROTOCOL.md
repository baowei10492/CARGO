# P25 仿射扰动（DiffRegCD 设置）下的选择性配准：预注册协议（2026-09-16）

> 授权：用户 2026-09-16 同意：错位改为 DiffRegCD 的仿射扰动、定位器改为 RoMa + 相似变换拟合，
> 数据集不变（LEVIR-CD、DSIFN-CD、WHU-CD），256 px 小块，干净 + 三档扰动。
> 本文件与 `configs/p25_affine_protocol.yaml` 在任何 P25 运行之前写定；看到结果后不得修改。
> 纪律：此前各线（P12–P24）的冻结产物与判定一字不动；第 1–3 步只读验证集；测试集只在第 5 步各用一次。

---

## 0. 缘由与定位

```text
平移协议下，第二正例未能成立（P15 DSIFN 伤害不足；P22/P24 WHU 在剧烈变化区定位失败，§156、§189.1）
DiffRegCD（WACV 2026）与 Morphing Through Time（arXiv 2025）在仿射扰动下报告了 WHU、DSIFN 上的对齐收益；
  二者均为自定扰动，领域内没有公认的错位基准（调研记录见主记录 §190）
本协议采用 DiffRegCD 论文表 1 的默认扰动，作为「已发表设置下的压力测试」，与平移协议并列报告，不替代它
必须披露：本协议写于平移线失败之后；±30° 旋转与 0.8–1.25 缩放大于正射影像的常见残余错位；
  LEVIR 测试集此前已读三次，第 5 步为第四次
```

## 1. 扰动

```text
来源：DiffRegCD 论文表 1 默认档——平移 U[−25, 25] px、旋转 U[−30°, 30°]、缩放 U[0.80, 1.25]，256 px 小块，
  cv2.getRotationMatrix2D 以小块中心构造后加平移（其公开脚本的默认值 ±16 px / ±20° / 0.90–1.15 不采用）
三档：第 k 档取上述范围的 k/3（围绕恒等变换），每个小块的均匀随机数在三档间共享（嵌套），第 3 档即原设置；
  随机数种子 = 项目种子 3407 × 小块编号
只扰动 T2；双线性插值；图外补零；标签始终在 T1 坐标系
小块：LEVIR 1024 px 图切 16 块，DSIFN、WHU 512 px 图切 4 块，不重叠
```

## 2. 定位器

```text
RoMa（outdoor 权重，融合局部相关扩展 fused-local-corr 0.1.1，与 P23/P24 同一环境）在 256 px 小块上稠密匹配，
  按每对固定的种子采样 5000 对 → 像素坐标换成 OpenCV 的「像素中心为整数」约定 →
  cv2.estimateAffinePartial2D（旋转 + 等比缩放 + 平移，RANSAC 重投影阈值 1 px、2000 次、置信度 0.999、
  精修 10 次），内点少于 8 记为未收敛（估计为恒等变换）
零扰动判定：估计变换在 17×17 网格上的平均位移 > 4 px 才算「有错位」（4 px = WHU 固有约 2 px 错位的两倍）
不训练、不微调
```

## 3. 第 1 步：无标签定位检查（本协议当前唯一可运行的一步）

```text
样本：三个数据集验证集的全部小块中均匀抽取至多 600 块；每块估计干净 + 三档
自检（先于测量）：每个数据集取前 20 块中灰度起伏最大的 3 块，把 T1 与其自身的第 3 档扰动配对，
  17×17 网格平均传递误差须 <= 1 px 且全部收敛；失败 → 该数据集 selfcheck_failed，不测量
误差：估计 A 与真值 M 在网格点上的平均传递误差（只计真值落在小块内的点），
  以及相对干净估计的差分误差（真值取 M∘A0，A0 为同一小块的干净估计；§188.2 的教训）
成功：收敛，且两种误差中较小者 <= 2 px
判据（每个数据集独立）：第 2、3 档成功率均 >= 0.80 → proceed_to_step2；否则 stop_localizer_insufficient
报告（不作判据）：第 1 档；干净小块的触发率（<= 0.10 为好）与估计位移；扰动幅度；按变化占比分箱的第 3 档成功率与干净触发率
标签使用：只为「变化占比」一列读取验证集标签；判据不用标签
```

## 4. 第 2 步：F1 关（第 1 步通过的数据集；运行前另写实现说明，判据现在写定）

```text
小块：该数据集验证集的全部小块；检测器：本文 DINOv3 检测器（LEVIR P12、DSIFN P15、WHU P8 的冻结检查点），
  在 256 px 小块上推理，不重训
路径：raw（扰动后的 T2）/ oracle（用真值 M 对回）/ estimated（用 A 无条件对回）/ estimated_gated（触发才对回）
打分像素：每个小块取「三档真值变换都把该点映射到小块内」的像素集合，干净与三档、所有路径共用
判据：
  第 3 档伤害 raw 干净 − raw 第 3 档 >= 0.05
  第 3 档天花板 oracle − raw >= 0.05
  第 2、3 档恢复率 (estimated − raw) / (oracle − raw) 均 >= 0.50 → proceed_to_step3
```

## 5. 之后各步（各自另写实现说明或协议）

```text
第 3 步 选择器：每个「检测器 × 数据集」重训（输入改为 RoMa 的内点数、内点比例、估计的旋转 / 缩放 / 平移、
  平均位移，以及两路检测的差异），在训练集中划出的校准部分标定阈值；判据：
  干净 F1 下降 <= 0.001；三档平均增益 >= 0.020；第 3 档增益 >= 0.050；第 3 档对 oracle 的恢复率 >= 0.50
第 4 步 跨检测器：LEVIR、DSIFN 用 P21 已训练的 BIT、CD-Lamba、CDxLSTM；WHU 上三者需新训练（另写协议）
第 5 步 一次性测试：全部冻结后，各数据集测试集各用一次；与 DiffRegCD 官方权重在同一小块、同一扰动下对比（只作报告）
```

## 7. 事前预期（写于运行前，不作判据）

```text
LEVIR：纹理丰富、变化稀疏，大概率通过
DSIFN：场景多样、变化面积大，中等把握
WHU：256 px 小块只覆盖约 19 m，可用于匹配的内容少，且验证条带中段变化极密（§189.1），风险最大
干净小块：RoMa 估计应接近恒等变换；WHU 上约 2 px 的固有错位低于 4 px 的触发线
```
