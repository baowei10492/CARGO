# P27 自研定位器设计方案（草案，2026-09-17）

> 性质：设计方案，不是预注册协议。实现前需用户确认第 10 节的决定，并另写 P27 预注册协议（门槛、划分、一次性使用）。
> 依据：主记录 §156–§159（P22）、§188–§189.1（P23/P24）、§190–§190.1（P25）、§191–§191.5（P26/P26-A）。
>
> **第一版的调整（2026-09-17，主记录 §192.1–§192.2）**：D1–D5 均按默认。旋转可行性检查显示冻结特征在 30° 时基本失配，
> 按用户决定第一版**不做旋转**：变换族为平移 + 等比缩放，评估用旋转固定为 0 的 P25 扰动（RoMa 在同一扰动下重跑作对照）。
> 同一检查显示步长 8 远好于步长 16，**粗阶段改为步长 8、细阶段为步长 4**；未训练的冻结特征在真实双时相对上几乎匹配不上，
> 在真实影像上训练适配层是必需的。下文第 3 节中的「相似变换」「步长 16」在第一版中分别读作「平移 + 缩放」「步长 8」。

## 1. 要解决的问题（由已有证据归纳）

| 已测定位器 | 暴露的问题 | 出处 |
|---|---|---|
| P7C（本项目，LEVIR 训练） | 只能估 ±8 px（2 px 步长）平移；变化密集时相关面被污染；无错位时也必须给出非零偏移（clean 误触发 33%） | §157、§188.2 |
| RoMa（零适配） | 自配对 0.02 px，但真实双时相 256 px 小块噪声大（LEVIR 干净小块平均位移 4 px）；变化越密越失败；WHU 小块崩溃 | §190.1 |
| DiffRegCD 配准头（按数据集训练） | 方向对但粗（8.2 px 一格的分类，自配对最差 14–19 px）；只在扰动样本上训练，无错位时报出 15–22 px | §191.3、§191.5 |

归纳成五条需求：

```text
R1 变换族：至少相似变换（平移 + 旋转 + 等比缩放），平移是其特例 —— 同时覆盖 P22/P24 的平移协议与 P25 的仿射协议
R2 精度：真实双时相 256 px 小块上，传递误差 <= 2 px（P25 成功口径）的比例 >= 0.80（第 2、3 档）
R3 知道「没有错位」：干净小块的触发率 <= 0.10（P7C 与 DiffRegCD 都在这里失败）
R4 变化密集时不失效：变化占比 >= 15% 的小块成功率不应显著低于低变化小块（三条现成路径都在这里失败）
R5 不被固有错位带偏：WHU 两期本有约 2 px 的稳定错位（§188.2），训练与评估都不能把它当成噪声或真值
```

## 2. 设计原则（每条对应上面的失败原因）

```text
P1 在真实双时相影像上训练（含真实的时相差异与真实变化），而不是只用「一张图对它自己的变形」—— 针对 RoMa 的双时相噪声
P2 显式回归连续的变换参数，用可微的加权最小二乘从稠密对应解出，而不是在粗类别上分类 —— 针对 DiffRegCD 的 8 px 粒度
P3 由粗到精：先在低分辨率全局匹配应对大位移与旋转，再在高分辨率局部细化到亚像素 —— 同时满足 R1 与 R2
P4 变化感知：每个位置学习一个「可用于配准」的权重，训练时用训练集的变化标签监督，并人工粘贴大面积假变化 —— 针对 R4
P5 训练样本中大量包含「无扰动」与「极小扰动」，并有专门的「是否错位」输出 —— 针对 R3
P6 用「两个已知扰动之间的相对变换」做主要监督，它与这对影像本身的固有错位无关 —— 针对 R5
P7 多数据集联合训练一个模型，并做留一数据集的泛化检验 —— 避免 DiffRegCD 那种「按数据集、同分布」的质疑
```

## 3. 网络结构

```text
输入：参照图 R（T1）与目标图 P（T2，可能被扰动），256×256（也可接受其他 16 的倍数尺寸）
输出：相似变换 S（把 R 上的点映到 P 上，与 P25 约定一致）、错位概率 p_mis、每位置的配准权重图

① 特征：冻结的 DINOv3 ConvNeXt-Tiny（项目检测器同一主干），取步长 16 / 8 / 4 三层，
   各接一个可训练的 1×1 适配层（到 128 / 96 / 64 维）并做 L2 归一化。
   冻结主干以减少过拟合、保留对光照与季节差异的稳健性；适配层学习「为配准服务」的嵌入
② 粗阶段（步长 16，16×16 个位置）：
   R 与 P 所有位置两两相关（256×256）→ 双向 softmax 得软匹配 → 每个 R 位置的期望匹配位置与置信度
   配准权重 w = 置信度 ×（1 − 变化概率），变化概率由一个小头从 R 特征与匹配到的 P 特征及其差估计
   加权 Umeyama（相似变换闭式解）+ 3 轮迭代重加权（Huber）→ S0；全程可微
③ 细阶段（步长 8，再步长 4）：
   用当前 S 把 P 反变换回 R 的坐标系（图像级 warp 后重新取特征，两次主干前向，256 px 下开销很小）
   局部相关（半径 3 个格点，即步长 8 时 ±24 px、步长 4 时 ±12 px）→ soft-argmax 得残差位移与置信度
   同样的变化感知权重与加权 Umeyama → 增量 ΔS，S ← ΔS∘S；步长 4 下 0.1 格即 0.4 px
④ 错位判断：由最终 S 在网格上的平均位移、各阶段残差与权重统计，经一个小 MLP 输出 p_mis
   （供选择器使用；是否错位不再靠「位移大于阈值」这种硬规则）
参数量：主干冻结，可训练部分约 1–2 M
```

## 4. 训练

### 4.1 数据

```text
各数据集训练集（只用训练集；其中各留 5% 作开发用保留集，验证集在门槛检验前不碰）：
  LEVIR-CD（1024 px，随机裁 256）、DSIFN-CD（512 px）、WHU-CD（训练区 512 px 瓦片）、GZ-CD（512 px）
  可选：HRCUS-CD（256 px，7975 对，与 LEVIR 同分辨率，增加多样性）
S2Looking 暂不纳入（侧视、固有错位大，标签坐标系需先核实）
```

### 4.2 样本构造（每个样本两份扰动，供相对监督）

```text
从一对 (T1, T2) 裁出 256 px 的 R = T1 块与 T2 块；对 T2 块独立采样两个相似变换 M1、M2，得到 P1、P2
扰动分布（刻意比测试更宽，且与 DiffRegCD 表 1 不同）：
  30% 恒等；20% 极小（平移 ±3 px、旋转 ±1°、缩放 0.99–1.01）；
  50% 大（平移 ±32 px、旋转 ±35°、缩放 0.75–1.33）
外观增强（只作用于 P）：亮度、对比度、色偏、模糊、噪声
人工假变化：以一定概率从其他影像粘贴若干块到 P（总面积至多 40%），其区域并入变化标签 —— 专门训练「变化密集」情形
```

### 4.3 损失

```text
L_rel    相对监督（主项）：S2∘S1⁻¹ 与 M2∘M1⁻¹ 的网格传递误差 —— 与 R、T2 之间的固有错位无关
L_self   自配对监督：同一 T2 块与其扰动版本（无时相差异、无固有错位），真值精确
L_abs    绝对监督：S1 与 M1 的传递误差，权重较低（假设原影像对已配准，WHU 等有固有错位的数据集会带来约 2 px 的噪声）
L_change 变化头：与变化标签（含人工假变化）的二值交叉熵，标签在 R（T1）坐标系，与粗阶段位置对齐
L_mis    错位头：恒等样本为 0，其余为 1 的二值交叉熵（极小扰动样本按位移大小给软标签）
三个阶段都施加传递误差损失（深监督），误差用 Charbonnier 形式
```

### 4.4 训练设置（初值）

```text
AdamW，学习率 3e-4，余弦衰减，批 16，约 50k 步，混合精度；单张 4090 预计 8–12 小时
开发期只看保留集上的 P25 式指标（成功率、干净触发率、变化分箱）；冻结后才在验证集上跑一次门槛检验
```

## 5. 评估

```text
E1 主检验：P25 第 1 步流程原样换入本定位器（LEVIR / DSIFN / WHU 验证集，同样 600 个小块、同样扰动），
   判据不变：第 2、3 档成功率 >= 0.80；另报干净触发率（本定位器以 <= 0.10 为设计目标）、变化分箱
E2 泛化：留一数据集训练（例如不含 DSIFN 训练，测 DSIFN 验证集）；以及「错配扰动」训练（只用平移 + 小旋转缩放训练，测表 1 全幅扰动）
E3 平移协议：WHU 物理位移（P22 窗口）上的跟踪精度，按差分口径（§188.2）报告，作为描述量
E4 对照（同一流程）：P7C、RoMa（零适配，已有）、DiffRegCD 配准头（已有自配对结果）、SIFT / 相位相关（已实现）；
   可选：用同样训练数据微调的 RoMa —— 回答「是不是随便微调一个强匹配器也行」
E5 消融：去掉变化头 / 去掉假变化 / 去掉恒等样本 / 去掉相对监督 / 去掉细阶段 / 单数据集训练
E1 通过的数据集 → 第 2 步（F1）与第 3 步（选择器），再到一次性测试（均另写协议）
```

## 7. 开发纪律（吸取前几轮的教训）

```text
开发与调参只用训练集中的保留集；验证集只在冻结后用于门槛检验，每个冻结版本只跑一次
若未通过，最多再做一轮有书面修订的改进；改进依据只能来自保留集与验证集上的无标签诊断
评估口径在开发前写死：P25 的直接误差与差分误差取较小者（§190），干净触发率，变化分箱
数据集之间超参一致；论文写明训练数据、扰动分布与测试扰动的关系
```

## 8. 风险

```text
1 旋转：DINOv3 特征不具旋转不变性，±30° 下粗阶段可能失配。
  开工第一步先做无标签可行性检查：冻结特征 + 未训练的粗阶段在自配对上对旋转的匹配成功率；
  不理想则在粗阶段加少量旋转假设（如 −30°…30° 共 5–7 个），或改用可训练的描述子
2 WHU 256 px 小块只覆盖约 19 m，内容太少时任何定位器都难；可另报「带更大上下文」的设置（实际应用中整景可得），
  但主结果仍按 P25 的 256 px 口径
3 固有错位与标签噪声：相对监督可消除前者，变化标签的质量影响变化头
4 训练不收敛或过拟合到某个数据集：留一数据集检验会暴露
```

## 9. 论文中的定位

```text
方法：变化感知、能判断「无错位」、输出连续相似变换的配准器 + 按任务收益选择性采用的框架（与检测器无关）
证据链：现成匹配器（RoMa）与按数据集训练的配准头（DiffRegCD）在变化检测所需精度上都不够，且后者会对已对齐的图报出大位移
  → 本文定位器在同一流程下通过 → 选择器在多个数据集上有效 → 一次性测试
```
