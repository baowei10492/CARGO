# P8-D：尺度/覆盖范围归因探针（预注册协议）

> 预注册时间：2026-07-26，在探针运行之前  
> 前置：图幅混淆已排除（主记录 75.1，LEVIR@512 retention 0.967）；
> 剩余未控制变量是**地面覆盖范围**（主记录 75.5）  
> 本探针是归因仪器，不能重开任何门槛：WHU 定位器阶段 A 的失败
> 判定在任何分支下保持不变。

## 1. 要区分的两种机制

```text
LEVIR@512 覆盖 256 m 地面；WHU@512 只覆盖 38.4 m（GSD 差 6.7 倍）。
机制 A（尺度/覆盖）：38 m 窗口内可供全局位移投票的独立结构太少，
  且固有失配在细 GSD 下的像素量被放大——换一个粗传感器就正常
机制 B（数据集属性）：WHU 的失配场在任何尺度下都不是全局平移
  （如跨航次视差场），粗传感器也救不了
```

二者对论文适用域条件的表述完全不同：A → "GSD/覆盖范围须足够"
（一般化、可预测）；B → "第二个空间变化场负例"。写错即核心论断错。

## 2. 设计：固定像素数，只改覆盖

把 WHU train 栅格切成更大的块再**整数倍 BOX 下采样**回 512：

```text
 512 → 512   覆盖  38.4 m   有效 GSD 0.075 m   S8 注入 = 0.60 m
1024 → 512   覆盖  76.8 m   有效 GSD 0.150 m   S8 注入 = 1.20 m
2048 → 512   覆盖 153.6 m   有效 GSD 0.300 m   S8 注入 = 2.40 m
3072 → 512   覆盖 230.4 m   有效 GSD 0.450 m   S8 注入 = 3.60 m
                                    （≈ LEVIR 的 8 px = 4.00 m）
```

BOX 下采样在整数倍时是精确的块平均，即粗传感器像素积分的物理模型；
所有 scale 都强制为 512 的整数倍（非整数倍直接报错）。注入在输出
空间进行（与既有协议一致），因此仪器几何完全不变，改变的只有内容。
注意最大覆盖下 S8 的物理量恰好接近 LEVIR 的 4 m——F8 的单位不可比
问题在该点上自动对齐。

方向为什么只能向下采样：反方向（把 LEVIR 裁小再上采样）已被否决
（主记录 75.5）——上采样销毁分辨率，8 px 注入会小于一个"有效像素"，
任务因信息不足而失败，与覆盖无关。

## 3. 取样与仪器

```text
区域：仅 train 栅格 x < 17408（train 列 0..33），y < 14848，
  永不触碰缓冲列与 val 条带；val 不足以支撑 3072 块（宽仅 3072，
  每行 1 块），train 区域则有充足面积
仪器：LEVIR P7C 定位器——它从未见过任何 WHU 数据（包括 train），
  因此在 train 区域测量不构成任何评估机会消耗或循环论证
块选择：确定性。stride = scale；若非重叠块数 < 60 则 stride =
  scale/2（接受半重叠相关性，stride 记录在案）；再均匀抽取至 60
标签：占位全零（探针不算任何带标签指标；全零使误算的 F1 呈显性
  退化而非似是而非）
scale0512 是一致性锚点：与 val 原生测量同配置但内容来自 train
  （change_fraction 0.036 对 0.095），只报告不设门槛
```

## 4. 判读（预注册）

主量：**最大覆盖（230.4 m）下的 Shift-4 conditional PCK@1**
（S4 的边界卷入最低；S8 照常报告并附 excess_boundary 注释，不判决）。

```text
>= 0.70 且 S4 PCK@1 随覆盖单调不减（容差 0.05）
  → coverage_explains_the_failure：
    适用域条件必须以 GSD/覆盖表述；
    WHU 不得被描述为"空间变化场"型负例
<= 0.30
  → coverage_does_not_explain_the_failure：
    数据集属性归因成立（仍带"该配置下"限定，见主记录 75.5）
其间，或端点高但中途塌陷（非单调）
  → partial_coverage_effect：两机制都不得单独主张
参照线随判定输出：LEVIR@512 S4 0.906；WHU 原生 val S4 0.132
样本量：每 scale <= 60 块，逐 scale 报告 n 与 stride（F6）
```

单调性条款防的是"端点偶然高"：中途塌陷说明趋势不是覆盖驱动的。

## 5. 边界

```text
不重开 WHU 阶段 A 门槛（decision.json 里 gates_reopened 恒 false）
不训练任何模型；不触碰任何 val/test 评估机会
不授权扩 search radius
若判 coverage_explains：后续"粗化 WHU 重建链条"（2048/0.3 m 重切
  →P3b→定位器）是新阶段，需新协议与用户批准，不在本协议内
```

## 6. 运行

```bash
bash scripts/run_p8_scale_probe.sh
```

流程：pytest → 构建探针（CPU 1–2 分钟，读 train 两幅大图）→
build_manifest → 四个 scale 各跑一次 offset 诊断（GPU 分钟级）→
`summarize_scale_probe` 固化判定。产物 `reports/p8_scale_probe/<UTC>/`。
