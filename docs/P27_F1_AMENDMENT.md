# P27 修订：跳过定位关，直接进入 F1 关（2026-09-17）

> 授权：用户 2026-09-17 决定「每个数据集 F1 有正收益即可」，并同意下述判据（主记录 §192.6）。
> 本文件与 `configs/p27_f1_gate.yaml` 写于 P27 第一版保留集诊断（§192.5）之后、任何 P27 定位器接触验证集之前；
> 看到任何 P27 F1 结果后不得修改。原协议 `docs/P27_LOCALIZER_EVALUATION_PROTOCOL.md` 的其余纪律继续有效。

---

## 1. 改了什么、为什么

```text
原协议：先过定位关（验证集第 2、3 档定位成功率 >= 0.80），通过的数据集再测 F1
修订后：不设定位关，直接测 F1；定位成功率照常计算，只作报告
理由：定位关是本项目自设的前置关，最终要回答的是「加定位器是否让检测更好」（导师 2026-08-15 的标准）；
  保留集诊断显示第一版在无双时相差异时几乎全部成功，失败集中在约 25–30% 的真实小块上，
  这些小块的错判对 F1 的影响只能由 F1 本身回答
必须披露：本修订写于看到第一版保留集结果（均未达 0.80）之后；原 F1 关（P25 协议第 4 节）的
  伤害 >= 0.05、天花板 >= 0.05、恢复率 >= 0.50 改为下述「正收益」判据，属于放宽，论文中如实说明，
  原三项照常报告
```

## 2. 测量

```text
定位器：P27 第一版 best.pth（第 40000 步），冻结；本次运行即为该检查点对验证集的唯一一次使用，
  计入「至多两个冻结版本」（与 E1 共用一次性标记）
检测器：本文 DINOv3 检测器的冻结检查点，不重训——LEVIR 用 P3b（P12 所用），DSIFN 用 P15，WHU 用 P8；
  在 256 px 小块上推理，阈值取各检查点配置（0.5）
小块：三个数据集验证集的全部不重叠 256 px 小块（LEVIR 64 图 × 16，DSIFN 823 图 × 4，WHU 174 图 × 4）
扰动：P27 评估配置（P25 去掉旋转）：平移 ±25 px、缩放 0.80–1.25 的 1/3、2/3、全幅三档 + 干净，只扰动 T2
路径：raw（扰动后的 T2）/ oracle（用真值矩阵对回）/ estimated（总用估计对回）/
  estimated_gated（定位器判为错位、即错位概率 > 0.5 时才对回，否则同 raw）
打分像素：每个小块取「三档真值变换都把该点映射到小块内」的像素，干净与三档、所有路径共用；
  各路径在全部小块上累计 TP / FP / FN 后算 F1
```

## 3. 判据（每个数据集独立）

```text
主路径 estimated_gated：
  第 2 档 F1(gated) − F1(raw) > 0，且第 3 档 F1(gated) − F1(raw) > 0，
  且干净小块 F1(raw) − F1(gated) <= 0.005
  → positive_gain；否则 no_positive_gain
仪器检查（不过则不给结论，记 instrument_failed）：干净 raw F1 >= 0.50；干净 oracle 与干净 raw 完全相同
报告（不作判据）：第 1 档；伤害（干净 raw − 各档 raw）；天花板（oracle − raw）；恢复率；
  不门控路径的收益与干净下降；定位成功率与触发率；按变化占比分箱的 F1
```

## 4. 之后

```text
positive_gain 的数据集：扩展到其他检测器（LEVIR、DSIFN 用 P21 已训练的 BIT、CD-Lamba、CDxLSTM；
  WHU 需新训练，另写协议），判据相同；全部冻结后各数据集测试集各用一次
no_positive_gain 的数据集：如实记为负例；第二版定位器（若做）只能依据保留集与本次运行的
  无标签量（触发率、定位行）写修订，且是最后一个可评估版本
若运行在写出结果前中断：标记已写入，重跑须先在主记录写明中断原因，再手工移除该标记
```
