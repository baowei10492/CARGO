## 0. 目的与数据范围

```text
回答两个问题：
  1. DiffRegCD 在目标数据上训练的配准头，在它自己的扰动（论文表 1）下能否把配准做到 2 px 以内？
     —— 分辨「它的高分来自配准准」还是「来自检测头在扰动数据上训练后能扛错位」（§190.2、§P13 线索）
  2. 若能，它可作为「按数据集训练的定位器」接入本项目，检验选择器（第 2、3 步另写实现说明）
数据集：LEVIR-CD、DSIFN-CD 的验证集
  WHU-CD 排除：本项目的 WHU 验证条带取自官方训练大图，DiffRegCD 的 WHU 头很可能在其上训练过，结果不可作证据
必须披露：DiffRegCD 按验证集挑选检查点（main.py），本项目的验证集即官方验证集，存在轻微的乐观偏差
```

## 1. 与 P25 第 1 步相同的部分（配置核对 P25 配置 sha256 561b7d29…）

```text
小块选择（每个数据集至多 600 个 256 px 小块，均匀抽取）、每块的扰动参数与三档、17×17 网格误差、
直接误差 / 相对干净估计的差分误差、成功 = 收敛且较小者 <= 2 px、
判据（第 2、3 档成功率均 >= 0.80 → proceed_to_step2）、按变化占比分箱、干净触发率（平均位移 > 4 px）
```

## 2. 不同的部分

```text
定位器：DiffRegCD（commit 6b9acb6c）冻结 DDPM 主干 + 该数据集的配准头（Hugging Face 权重，核对 LFS sha256），
  不加载检测头；取第一个时间步 t = 50 的第 11 层解码特征送入配准头（与其训练代码 optimize_parameters 一致）；
  扩散噪声按「项目种子 × 小块编号」固定，同一小块的干净与三档共用同一份噪声（P13 的做法）
扰动对象：T1（DiffRegCD 训练时被扰动的是其「A」图，即前时相），T2 为未扰动的参照（其「B」图）；
  扰动矩阵与 P25 相同，只是作用在 T1 上
位移场 → 相似变换：粗网格每个格点按 align_corners=True 对应到 256 px 小块上的像素位置；
  归一化位移 × (尺寸 − 1) / 2 换成像素；RANSAC 相似变换拟合（重投影阈值 2 px、2000 次、0.999、精修 10、内点 >= 8）。
  阈值取 2 px 而非 RoMa 的 1 px：该位移场由 8.2 px 一格的 32×32 类别解码而来
约定标定（先于测量，只用自配对）：
  其训练损失的解码（对 logits 再除一次温度、在 linspace(−1, 1, 32) 码本上求期望）与前向解码
  （在 linspace(−1+1/32, 1−1/32, 32) 码本上求期望）不同；位移场所在网格（参照图或被扰动图）与正负号在代码中也不唯一。
  对每个数据集取与 P25 相同规则选出的 3 个自配对（T1 对自身第 3 档扰动），在 2 种解码 × 2 种符号 × 2 种网格共 8 种约定下
  计算最差传递误差；取最小者，须 <= 2 px，且不超过任何不同符号或网格约定的 0.5 倍；否则该数据集 selfcheck_failed，不测量
```
